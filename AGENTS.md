# Project working agreements

## Property and development media

Follow [docs/media-storage.md](docs/media-storage.md) when importing or updating
property media. Download supported source media to server storage, optimize it,
deduplicate by content, and serve local URLs with browser caching. PostgreSQL
stores metadata and URLs rather than the media binaries.

Inspect the complete supplied project folder, including descriptions, brochures,
photos, videos, location materials and plans. Enrich the page with verified facts
and distinct media sections. Keep general project footage at project level and
assign villa-specific media only when its content supports that assignment;
filenames alone are insufficient. Do not duplicate the same gallery in the hero
and interiors section or assign sample-villa photos to every villa type.

Stage imports and review reports before applying data atomically. Reuse cached
encodings, preserve source files and backups, and verify media loading on the
published page. Follow the existing storage-safety and proportionate-verification
agreements; this workflow does not authorize cleanup or unrelated release work.
