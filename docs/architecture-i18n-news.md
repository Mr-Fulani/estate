# Estate: локализация и новости

Этот документ фиксирует контракт реализации. Порядок работ и соглашения не
меняются во время реализации без отдельного решения.

## Локали и URL

- Поддерживаемые локали: `ru`, `en`, `tr`.
- Локаль по умолчанию: `ru`.
- Все публичные страницы используют префикс локали: `/ru`, `/en`, `/tr`.
- Старые публичные URL перенаправляются на русскую версию с сохранением пути и
  query-параметров.
- Административная часть остаётся на русском и доступна по `/admin`.
- Переключатель языка сохраняет текущий раздел и, где возможно, slug записи.

## Статические и динамические переводы

- Тексты интерфейса хранятся в типизированных словарях фронтенда.
- Недвижимость сохраняет существующие русские `title` и `description` для
  обратной совместимости и получает связанные переводы `ru`, `en`, `tr`.
- Если перевод объекта отсутствует, публичная страница использует русский
  текст. Интерфейс при этом остаётся на выбранном языке.
- Новость содержит общий slug и отдельные переводы заголовка, анонса, текста и
  SEO-полей для каждой локали.

## Модель новости

`NewsArticle`:

- `id`, `slug`, `cover_image`, `author`;
- `is_published`, `published_at`, `created_at`, `updated_at`;
- связанные `NewsTranslation` с уникальной парой `(article_id, locale)`.

`NewsTranslation`:

- `locale` (`ru`, `en`, `tr`);
- `title`, `excerpt`, `content`;
- `meta_title`, `meta_description`.

## API

Публичные методы:

- `GET /api/v1/news?locale=ru&page=1&per_page=9` — опубликованные новости;
- `GET /api/v1/news/{slug}?locale=ru` — опубликованная новость;
- при отсутствии запрошенного перевода API использует русский.

Административные методы:

- `GET /api/v1/news/admin/all` — список со всеми переводами;
- `GET /api/v1/news/admin/{id}` — запись со всеми переводами;
- `POST /api/v1/news`, `PUT /api/v1/news/{id}`, `DELETE /api/v1/news/{id}`.

## SEO и интерфейс

- Корневой layout задаёт локализованные базовые метаданные. Список новостей и
  каждая статья получают собственные `title`, `description`, canonical и
  `hreflang`.
- Статья формирует metadata из своего перевода и использует обложку как
  социальное изображение.
- Список новостей имеет пагинацию, состояния загрузки, ошибки и пустого списка.
- Админская форма показывает три языковые вкладки, статус заполненности и
  предпросмотр обложки.
